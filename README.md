# 💼 drr download mp4

Repository with the simple functionality of downloading videos directly upon upload.  

## 🛠 Technologies used
- **C# .net** (framework)  
- **JavaScript** (interactivity)  
- **HTML5** (markup)  
- **Visual Studio** (development environment)  
- **Github Pages** (deployment and hosting)

## 🚀 How to run this project
```bash
# Clone the repository
git clone https://github.com/DanielCoronelPV/drr-download-mp4.git

# Navigate into the project folder
cd drr-download-mp4

# Run the development server
dotnet watch run

# The app will be available at
http://localhost:5089/
```
